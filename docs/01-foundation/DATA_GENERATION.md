# TraceDrop Synthetic Data Generator

Complete, production-ready Python script for generating FHIR-compliant synthetic medical data for Phase 1 prototype.

## Quick Start

```bash
# Generate default dataset (300 donors, 900 donations, 2700 observations)
python3 data/generate.py --seed 42 --output data/synthetic/

# Custom configuration
python3 data/generate.py --seed 42 --donors 100 --output /path/to/output
```

## Output

The generator produces 7 files in the output directory:

- **fhir-bundles.jsonl** (1.8 MB): FHIR-compliant bundles, one per donor (300 lines)
- **donors.json** (243 KB): 300 donor profiles with demographics, languages, health history
- **donations.json** (652 KB): 900 donation events (3 per donor, spread over 3 years)
- **observations.json** (1.7 MB): 2700 vital observations (BP, Hb, RBC)
- **lab_reports.json** (12 KB): 20 synthetic lab reports with 6 formats
- **findings.json** (1.9 KB): ~9 findings generated by protocol rules
- **ground-truth.json** (1.7 KB): Metadata, personas, and statistics for testing

## Data Characteristics

### Donors (300)
- **Gender**: 85% M, 15% F (realistic blood donor demographic)
- **Age**: Concentrated 22-40 (Gaussian: μ=32, σ=6), range 18-60
- **Languages**: Bengaluru distribution
  - Kannada 35%
  - Hindi 30%
  - English 25%
  - Tamil 5%
  - Telugu 5%
- **Locations**: All Bengaluru-based

### Donations (900)
- **3 per donor** spread over 3 years
- **Deferral rate**: ~15% (realistic)
- **Centres**: 3 blood centres (Centre-1, Centre-2, Centre-3)

### Observations (2700)
- **BP readings**: Realistic distribution with some trending
  - Typical systolic: μ=128, σ=12 (range 95-180)
  - Typical diastolic: μ=78, σ=8 (range 60-120)
- **Hb readings**: Gender-specific
  - Males: μ=14.0, σ=0.9 g/dL
  - Females: μ=13.0, σ=0.8 g/dL
- **RBC counts**: 4.5 ± 0.5 × 10^6/uL

### Protocol Rules Implemented

All findings follow protocol rules from `docs/03-build/protocol-rules.md`:

| Rule | Condition | Finding |
|------|-----------|---------|
| **BP-G1** | SBP 140-159 or DBP 90-99 | BP_GRADE1 |
| **BP-G2** | SBP 160-179 or DBP 100-109 | BP_GRADE2 |
| **RF-BP-2** | SBP ≥180 or DBP ≥120 (no symptoms) | BP_URGENCY |
| **HB-DEF** | Hb < 12.5 g/dL | HB_BELOW_DONOR |
| **HB-SEV** | Hb < 8.0 g/dL | HB_SEVERE |
| **DM-PRE** | HbA1c 5.7-6.4% or FPG 100-125 | DM_PREDIABETES |
| **DM-DIAB** | HbA1c ≥6.5% or FPG ≥126 | DM_POSSIBLE |
| **TTI-FLAG** | Reactive screen | COUNSELLING_REQUIRED |
| **BP-TREND** | ≥3 rising readings | BP_RISING |

- UUID-based full URLs for every resource

- Seed: 42 (fixed for reproducible datasets)

### Performance
- Generates 300 donors in **<1 second**
- Output files fit in ~8.9 MB total

## Lab Report Formats

20 synthetic lab reports generated in 6 formats:

1. **CBC**: Hb, WBC, Platelets
2. **HbA1c Profile**: HbA1c, FPG
3. **Lipid Profile**: Total Cholesterol, HDL, LDL, Triglycerides
4. **Thyroid Screen**: TSH, T3, T4
5. **Liver Function**: ALT, AST, Bilirubin
6. **Renal Function**: Creatinine, BUN

Each test includes reference ranges and realistic values with ~10% abnormal results.

## Usage Examples

### Python API

```python
from data.generate import SyntheticDataGenerator

# Create generator with custom configuration
gen = SyntheticDataGenerator(seed=42, output_dir="data/synthetic")

# Run generation pipeline
gen.run(donors=300)

# Or access generated data directly
donors = gen.donors
donations = gen.donations
observations = gen.observations
findings = gen.findings
```

### Command Line

```bash
# With custom seed and output location
python3 data/generate.py --seed 123 --output output/

# Generate fewer donors for quick testing
python3 data/generate.py --seed 42 --donors 50 --output /tmp/test/

# Verify output
wc -l data/synthetic/fhir-bundles.jsonl      # 300 lines
ls -lh data/synthetic/                       # All 7 files present
```

## Testing & Validation

Use the `ground-truth.json` file for testing and validation:

```python
import json

gt = json.load(open("data/synthetic/ground-truth.json"))

# Verify counts
assert gt["metadata"]["total_donors"] == 300
assert gt["metadata"]["total_donations"] == 900
assert gt["metadata"]["total_observations"] == 2700

# Check expected personas
personas = gt["personas"]
assert "D-001" in personas  # Arjun
assert personas["D-001"]["bp_trend"] == "rising"

# Verify findings were generated
findings_by_type = gt["statistics"]["findings_by_type"]
assert findings_by_type.get("BP_GRADE1", 0) >= 1
assert findings_by_type.get("HB_BELOW_DONOR", 0) >= 1
```

## Code Structure

- **SyntheticDataGenerator**: Main class
  - `generate_donors()`: Create donor profiles
  - `generate_donations()`: Create donation events
  - `generate_observations()`: Create vital sign observations
  - `_generate_findings_for_donor()`: Apply protocol rules
  - `generate_lab_reports()`: Create lab test data
  - `generate_fhir_bundles()`: Package as FHIR bundles
  - `save_json_files()`: Write output files
  - `generate_ground_truth()`: Create validation metadata

## Dependencies

- Python 3.7+
- Standard library only: `json`, `random`, `argparse`, `datetime`, `pathlib`, `typing`, `uuid`
- No external medical libraries (intentional for simplicity)
