What's inside

Features

🩸

Impact story & postcard

Follow red cells, platelets and plasma to anonymous patients; share a downloadable postcard. Details appear only when 5+ patients share them.

💬

Drop — the AI assistant

A Gemini agent with 18 tools on an agent runtime, on every screen, in six languages. It explains results, shows charts, offers slots, sets reminders, and remembers your schedule and language.

📄

Lab-report reader

Photograph any lab's report; Gemini extracts 16 LOINC-coded markers, range-checked. Nothing is saved until you confirm.

🎯

Care Goals

Readings become one Goal with tagged steps citing medical guidance — written by rules, confirmed by a doctor.

🚨

Safety-first Cards

Dangerous readings surface an urgent Card that always sits first and can't be hidden or deferred by the AI.

🔁

Return & re-donate

Check-ins track progress; when a Goal is reached, a countdown to the next eligible donation date appears.

🏅

Badges & Circles

Milestones ("5 patients", "Helped a child") and shared views for family, workplace and friends.

🛡️

Health cover (illustrative)

Modelled cover can rise with a steady health score, at the same premium — only with consent, and only the score is shared.

🗂️

Your data

See everything kept about you, and delete any of it. Guest sessions never touch the cloud.

Built on Google

Where we use Google services

Pratidaan is built end-to-end on Google Cloud. Every AI feature runs on Gemini via Vertex AI, and the app, data and sign-in are all Google.

Gemini 3.1 Flash-Lite
Drop's agent reasoning, lab-report OCR, and intro translation — the only places AI is used.
Vertex AI
Managed, global endpoint that serves Gemini to the backend.
Vertex AI Agent Engine
Agent runtime for Drop's tool-use loop, plus Sessions and Memory Bank when configured — with a built-in local fallback.
Cloud Run (asia-south1)
One serverless container hosts the API and serves the built web app; auto-scales, scales to zero.
Firestore
Stores signed-in users, sign-in history and bookings. Guests never touch it.
Google Sign-In
Identity via Google ID token, with an HMAC session cookie.
Google Calendar
Optional donation / check-up events in the donor's own calendar.
Gmail
Booking confirmations in the donor's own account (marked as a demo slot).

If Gemini is ever unavailable, every feature falls back to deterministic rules and says so — the app keeps working.

Under the hood

Architecture — rules decide, Gemini helps

Anything touching safety, money or privacy is deterministic code and is unit-tested (162 tests). Gemini is used only where rules can't do the job, running on an agent runtime with Sessions & Memory — and every AI output is checked by code before it's used.

Trust

How it stays safe and honest

Deterministic safety

Every safety, money and privacy decision is a tested rule, not a model output. The same history always gives the same result.

Human-in-the-loop

Nothing from a lab report is saved until the donor confirms it, and a doctor confirms every finding.

Graceful degradation

If Gemini is down, rules take over and the app keeps working — and says when an answer came from rules.

Privacy by design

A patient detail appears only when 5+ patients share it; dates are rounded to the month; the patient is never named.

All data in the prototype is synthetic. It is not a medical device, and care is never payment for blood — a donor who is turned away gets exactly the same care.
