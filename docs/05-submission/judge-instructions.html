Pratidaan (Drop assistant)

Voluntary blood donor app for India: impact tracing, donation health panel, illustrative health-linked cover, and AI assistant Drop. Deployed on Google Cloud Run (asia-south1); models on Vertex AI (Gemini 3.1 Flash-Lite).

Guardrails (three layers)

Implemented in backend/src/ai/guardrails.js. Static checks and prompts stay aligned; every Gemini call gets the same safety appendix via llm.js (guardrailKind).

1. Before the model (Drop chat only)

Regex on the donor’s message: block diagnosis/prescription asks, off-topic (crypto, homework, …), and emergency wording with a fixed reply (often + check-up card). The LLM is not called when blocked.

2. In every system prompt

augmentSystem() appends shared rules: Pratidaan scope only, no diagnose/prescribe, emergencies → call emergency services, facts from tools / given text only.

KindFeature

donor_copyHome insight, Card wording (default for other calls)

3. After the model

Drop chat: sanitizeReply() strips prescription-like wording. Copilot also enforces Drop’s own system rules (two sentences, tools for facts, no invented labs, anonymous recipients, illustrative slots).

  • Structured JSON outputs are schema-validated locally; Card rewrites must match rule text word-for-word.
  • Rule-based fallback() when Vertex is unavailable or the reply is incomplete.
  • Tests: backend/test/guardrails.test.js.

Known limits

  • Blood centre / clinic slots are not real reservations; Calendar events may be created but do not confirm a centre.
  • Cover and premiums are an illustrative model, not issued insurance.
  • AI rate limits (production): ~500k tokens/day and 2k calls/day per instance, 10 req/s; Cloud Run scales to 4 instances (concurrency 20).
  • Firebase is not used — only Cloud Firestore for signed-in accounts (via @google-cloud/firestore).
  • Agent Platform (Option C — sidecar): Gemini on Vertex + Agent Engine Sessions & Memory Bank in us-central1 (reasoning engine pratidaan-platform; no separate ADK deploy). Donor replies still use Cloud Run runAgent(); Sessions mirror chat; Memory Bank syncs “remember” facts (debounced). Setup: docs/AGENT_PLATFORM_SETUP.md. Status: /api/health → agentPlatform.engineConfigured.
